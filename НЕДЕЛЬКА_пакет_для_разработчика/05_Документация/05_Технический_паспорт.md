# Технический паспорт

## Технологии
- HTML5
- CSS3
- Vanilla JavaScript
- Без фреймворков
- Без CDN

## Особенности
- Адаптивная вёрстка.
- Sticky-навигация.
- Динамическая карточка первого экрана.
- Каталог практикумов генерируется из JS-массива.
- Стили изолированы внутри `.nedelka-root`.
- Предусмотрены desktop/tablet/mobile состояния.

## Точки для дальнейшей разработки
- интеграция CMS;
- динамическая загрузка практикумов;
- реальные фото;
- платёжная система;
- регистрация;
- аналитика;
- логотипы партнёров;
- SEO/OpenGraph;
- при необходимости микроразметка событий.

## Файлы исходников
- `index.html` — структура страницы.
- `styles.css` — весь дизайн и адаптив.
- `script.js` — карточки, интерактив и уведомления.

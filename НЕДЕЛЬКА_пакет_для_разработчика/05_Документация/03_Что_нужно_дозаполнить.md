# Что необходимо дозаполнить перед запуском

## Практикумы
Для каждого события предоставить:
- ФИО эксперта;
- регалии / должность;
- тема практикума;
- дата и время;
- прошедший / предстоящий;
- стоимость, если отличается от 1 500 ₽;
- ссылка на оплату;
- ссылка на регистрацию;
- фото эксперта;
- при необходимости краткое описание результата практикума.

## Партнёры
Для каждого партнёра:
- официальный логотип;
- ссылка на сайт / ресурс.

Список из ТЗ:
1. Креативное Поколение
2. VIDMK
3. Skillouth
4. Артилект
5. Repka Ai

## Интеграция
Определить:
- конечный URL страницы;
- нужно ли использовать шапку/подвал основного сайта парки.рф;
- нужна ли авторизация;
- нужна ли встроенная оплата;
- нужна ли CRM/форма;
- Яндекс Метрика / цели;
- политика обработки персональных данных, если появятся формы.

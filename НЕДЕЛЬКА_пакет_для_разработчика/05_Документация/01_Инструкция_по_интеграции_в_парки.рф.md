# Инструкция по интеграции лендинга «НЕДЕЛЬКА» в парки.рф

## 1. Рекомендуемая схема
Создать отдельную страницу проекта на текущем сайте, например:
- `/nedelka/`
- либо другой URL по решению администратора сайта.

Использовать содержимое `02_Исходники/index.html` как основу страницы.

## 2. CSS
Подключить `styles.css` только на странице проекта.

Все основные стили ограничены контейнером `.nedelka-root`. Это снижает риск конфликтов с глобальными стилями парки.рф.

Если CMS автоматически меняет стили ссылок, заголовков или кнопок, приоритет следует отдавать стилям внутри `.nedelka-root`.

## 3. JavaScript
Подключить `script.js` после разметки страницы либо с `defer`.

Скрипт отвечает за:
- генерацию карточек практикумов;
- уведомления для незаполненных ссылок;
- динамическую смену навыков в календарной карточке первого экрана.

## 4. Изображения
Перенести логотипы в директорию медиа проекта и обновить пути в HTML.

В текущей версии используются:
- `makers-logo.png`
- `parks-logo.png`

Полные варианты логотипов находятся в `03_Материалы/Логотипы/`.

## 5. Контент практикумов
В `script.js` найти массив:
`const practicals = [...]`

Для каждой карточки заменить:
- `name` — имя эксперта;
- `meta` — должность / регалии;
- `topic` — тема практикума;
- `cta` — текст кнопки;
- `url` — ссылка на оплату или регистрацию;
- `status` — `past` или `future`;
- `statusLabel` — подпись статуса.

## 6. Фото экспертов
Текущая версия содержит графический placeholder.

Для боевой версии рекомендуется добавить поле `photo` в массив `practicals` и выводить фото через `<img>` или `background-image`. Все фото желательно привести к единой цветокоррекции и единому соотношению сторон.

## 7. Партнёры
В HTML в блоке `#partners` сейчас стоят текстовые заглушки.

Необходимо:
- заменить текст на реальные логотипы партнёров;
- добавить реальные URL;
- сохранить hover-эффект.

## 8. Формы и аналитика
По ТЗ отдельная форма не описана. Текущие CTA ведут на ссылки практикумов.

При необходимости можно подключить:
- форму регистрации;
- CRM;
- аналитику Метрики;
- события на клики по CTA;
- UTM-параметры.

## 9. Проверка адаптива
Обязательно проверить:
- 1440 px и выше;
- 1280 px;
- 1024 px;
- 768 px;
- 390–430 px;
- iPhone Safari;
- Android Chrome.

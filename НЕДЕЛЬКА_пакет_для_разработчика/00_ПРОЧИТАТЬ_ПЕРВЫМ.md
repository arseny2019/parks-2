# НЕДЕЛЬКА — пакет для передачи разработчику

## Назначение
Пакет содержит материалы для подключения лендинга образовательного проекта «НЕДЕЛЬКА» к сайту «Парки России» (парки.рф).

Проект: совместный образовательный проект «Мэйкерс» × «Парки России».

## Что находится в архиве
- `01_ТЗ/` — исходное техническое задание.
- `02_Исходники/` — HTML, CSS, JS и логотипы, используемые текущей версией.
- `03_Материалы/Логотипы/` — все переданные варианты логотипов «Мэйкерс» и «Парки России».
- `04_Превью/` — готовая версия для локального просмотра в браузере.
- `05_Документация/` — рекомендации по интеграции, контенту, ссылкам и проверке перед публикацией.

## Быстрый просмотр
Открыть файл:
`04_Превью/НЕДЕЛЬКА_лендинг_превью.html`

## Основные исходники
- `02_Исходники/index.html`
- `02_Исходники/styles.css`
- `02_Исходники/script.js`

## Важное по интеграции
1. CSS лендинга изолирован классом `.nedelka-root`, чтобы минимизировать конфликт с основным сайтом.
2. Внешние библиотеки и CDN не используются.
3. Карточки практикумов формируются в `script.js` из массива `practicals`.
4. Реальные данные экспертов, фото, ссылки оплаты/регистрации и ссылки партнёров в исходном ТЗ не переданы — сейчас стоят шаблонные значения.
5. Перед публикацией необходимо заменить шаблонные данные и проверить ссылки.
6. Для сайта парки.рф рекомендуется либо подключить лендинг как отдельный шаблон/страницу, либо перенести блок `.nedelka-root` внутрь существующего шаблона сайта вместе со стилями и скриптом.

## Контрольная версия
Текущая сборка включает логотипы «Мэйкерс» и «Парки России» в шапке, первом экране и нижней части страницы.
